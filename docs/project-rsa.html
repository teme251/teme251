RSA Operational Analytics & Performance Review

An operational analytics interface that connects weighted performance indicators, structured service observations, and individual coaching context. The work explores how supervisors move from team-level signals to the evidence behind an individual review.

Operational analyticsWeighted scorecardsStructured observationsJavaScriptChart.js

Analytical objective

Connect performance reporting with the context needed for a meaningful review. The RSA project family explores three complementary workflows: capturing observations, reviewing performance signals, and examining individual trends.

Engineering contribution

RSA Monitor provides weighted scorecards, summary metrics, a searchable and sortable associate table, and an individual detail drawer. The related observation portal collects category ratings, checklist responses, notes, and customer counts. The reporting interface adds date-range analysis, category averages, checklist completion, and individual trend visualization.

Application architecture

The interfaces use HTML, CSS, and JavaScript. RSA Monitor runs directly from sample records. The observation portal maintains its associate list in browser localStorage and submits structured JSON to a configured backend endpoint. The reporting interface consumes a JSON data contract and uses Chart.js for individual trends. The backend is outside the public repositories.

Technical significance

The work demonstrates the connection between data contracts, interaction design, and operational interpretation. Each interface exposes a different level of detail while preserving a path from a summary indicator to the observations that provide context.

Evaluation approach

Review search and sorting behavior, check consistency between summary and detail views, and trace displayed scores to the sample records. The focus is on traceability, interaction consistency, and clear presentation.

Status & access

Public prototypes use sample data. Employer systems and data are private.
