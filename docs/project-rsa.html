RSA performance tools

A browser-based performance analytics prototype with weighted scorecards, searchable and sortable associate records, and individual coaching views.

HTMLCSSVanilla JavaScriptWeighted scorecardsSearch & sorting

Problem & intended value

Operational scorecards need more than a summary number. This prototype explores how a supervisor can inspect the contributing performance categories and connect observations to a coaching discussion.

Implementation

Built in HTML, CSS, and vanilla JavaScript, the RSA Monitor combines summary metrics with a searchable, sortable associate table. A detail drawer exposes category scores, checklist items, strengths, and coaching notes, allowing exploration from an overview to an individual record.

Technical approach

Sample records in JavaScript → weighted score and status presentation → searchable and sortable table → associate detail drawer. Related repositories explore structured observations and performance reporting.

Engineering considerations

Maintain a coherent view across summary metrics, record ordering, and individual details. Information hierarchy matters: the interface should expose relevant context without overwhelming the reviewer.

Evaluation approach

Review search and sorting behavior, check consistency between summary and detail views, and trace displayed scores to the sample records. The focus is on traceability, interaction consistency, and clear presentation.

Status & access

Public prototypes use sample data. Employer systems and data are private.
